## 編譯說明

需要完整的 TeX 發行版（TeX Live 或 MiKTeX），並使用 **XeLaTeX** 編譯。

```bash
# 技術經濟與工程管理
cd 技术经济与工程管理
xelatex main.tex
xelatex main.tex        # 生成目錄與頁碼，需要跑兩遍

# 數據庫期末複習題
xelatex xjtu研究生数据库课程期末复习题2026.tex
```

- `main.tex` 使用 `ctexbook` 文檔類，依賴 `ctex`、`amsmath`、`fancyhdr`、`longtable` 等宏包
- 複習題使用 `ctexart` + `tcolorbox`（答案框）+ `enumitem` + `booktabs`
- 複習題的 B+ 樹插圖位於 `figs/` 目錄（8 張 PNG），編譯時需與 `.tex` 文件放在同一目錄
